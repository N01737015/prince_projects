# Maple Electronics

Maple Electronics is a full-stack web application developed to provide a modern platform for managing and interacting with electronic products through a secure and scalable architecture.

This project was built using a frontend and backend architecture while incorporating authentication, database management, containerization, and deployment-related technologies commonly used in modern software development.

## Features

* Secure user authentication and authorization
* Product and data management functionality
* Frontend and backend separation
* Database integration
* Containerized application environment
* Structured project architecture for scalability and maintenance

## Technologies Used

* React
* Node.js
* MongoDB
* Docker
* Keycloak
* Nginx
* JavaScript
* HTML5
* CSS3
