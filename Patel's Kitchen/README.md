# Patel's Kitchen

Patel's Kitchen is a responsive restaurant website created using HTML and CSS during my first semester of Computer Programming & Analysis.

This project focuses on clean frontend design, responsive layouts, structured navigation, and user-friendly UI development. I designed and developed the website independently while learning the fundamentals of web development.

## Features

* Responsive restaurant website layout
* Navigation bar and multiple sections
* Menu and food showcase design
* Contact and location section
* Clean UI with custom CSS styling

## Technologies Used

* HTML5
* CSS3

## What I Learned

* Frontend webpage structure
* Responsive web design basics
* CSS styling and layout management
* Website organization and UI design principles
