# PawConnect

PawConnect is a mobile application developed using React Native and Redux that helps users explore and connect with pets through a clean and interactive interface.

This project was created during my third semester while learning mobile application development, state management, and API integration concepts.

## Features

* Browse and view pet information
* Interactive mobile UI design
* Redux state management
* API data fetching
* Organized component-based architecture
* Responsive mobile application structure

## Technologies Used

* React Native
* JavaScript
* Redux Toolkit
* Expo

## What I Learned

* Mobile application development using React Native
* State management with Redux
* API integration and data handling
* Component reusability and project organization
* Frontend mobile UI development
