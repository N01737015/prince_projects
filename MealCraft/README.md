# MealCraft

MealCraft is a mobile recipe application developed using React Native and Redux that allows users to explore meals, view recipe details, and manage favorite recipes through an interactive and user-friendly interface.

This project was created to strengthen my mobile application development skills while working with state management, navigation, and structured frontend architecture.

## Features

* Browse and explore meal categories
* View detailed recipe information
* Add and manage favorite meals
* Interactive mobile UI and navigation
* Redux state management
* Organized component-based structure

## Technologies Used

* React Native
* JavaScript
* Redux Toolkit
* Expo

## What I Learned

* Mobile application development using React Native
* State management with Redux Toolkit
* Navigation and screen management
* Component organization and reusable UI design
* Building interactive frontend mobile applications
